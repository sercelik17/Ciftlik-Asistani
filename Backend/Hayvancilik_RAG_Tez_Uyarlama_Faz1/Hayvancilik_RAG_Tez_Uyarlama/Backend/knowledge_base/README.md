# Bilgi Tabanı

Bu klasöre tezde kullanılacak **güvenilir ve kaynak gösterilebilir** hayvancılık dokümanlarını koyun.
Desteklenen formatlar: `.pdf`, `.txt`, `.md`.

Önerilen konu klasörleri:

- `mastitis/`
- `sut_kalitesi/`
- `besleme/`
- `metabolik_hastaliklar/`
- `buzagi_sagligi/`
- `ureme/`
- `hayvan_refahi/`

Tercihen Tarım ve Orman Bakanlığı, üniversiteler, FAO, bilimsel dergiler ve veteriner fakülteleri gibi güvenilir kaynaklar kullanın.
Her dokümanın bibliyografik bilgisini ayrıca tez veri/kaynak envanterinde tutun.
